### Part 3: Mason's B3 additions (given 2026-11-11, started after part 1)

1. **Splunk attack_data, Windows side.** Extend the attack_data loader beyond auditd to the
   Windows datasets: Sysmon, Security, PowerShell and the other Windows channels Bastion reads
   or will read after the B3 routing work. Pull selectively with git LFS include filters, cache
   outside the repo under `%LOCALAPPDATA%\bastion\corpora`, and pin the commit. Technique labels
   come only from each dataset's own YAML metadata. Record the Apache 2.0 license in the
   manifest. Report disk usage before pulling anything over 5 GB and wait for Mason's OK.
2. **Label the unlabelled EVTX-ATTACK-SAMPLES files** (127 positive captures are currently
   unlabelled). Labels come only from the author's own materials: the labels sheet, directory
   names, file names and the repository's descriptions. A label is never derived from what
   Bastion detects on the file (that would be circular). Each label records its source and a
   confidence (exact, inferred from name, ambiguous). Ambiguous files stay unlabelled and are
   listed.
3. **Split integrity.**
   - The existing 130 capture test split stays frozen. New captures never change existing dev
     or test assignments.
   - New captures are assigned to dev or test with the manifest's fixed seed, stratified by
     technique, before any rule runs against them, and the assignment is logged in the
     contamination log.
   - Two headline sets are reported side by side: the original frozen 130 (so B1 and B2
     comparisons stay valid) and the expanded test split.
   - Results are reported per corpus as well as combined, so a lift that comes from one
     source's quirks is visible.
4. **Context hygiene.** Work from file names, metadata, labels and counts. Raw attack log
   contents are not printed or read into the working conversation unless a specific parsing
   bug requires one event, and then only that event.
5. **New ceiling report.** How many techniques now have at least one labelled capture (up from
   74 in the test split), how many of the 604 previously unlabelled techniques gained coverage,
   and the before and after detection rate on both headline sets.
